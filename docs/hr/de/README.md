# Arbeitszeit — das Handbuch

Alles über die Arbeitszeiterfassung hier, geschrieben für alle, denen das noch
nie jemand gezeigt hat. Keine dieser Seiten setzt voraus, dass Sie das System
kennen, und keine setzt voraus, dass Sie sich mit Computern auskennen.

Sie müssen nicht alles lesen. Suchen Sie die Seite, die zu Ihrer Frage passt,
lesen Sie sie und hören Sie dann auf.

Dasselbe Handbuch gibt es auf [English](../en/README.md) und
[فارسی](../fa/README.md).

## Wenn Sie neu hier sind

Lesen Sie zuerst **[Hier beginnen](01-start-here.md)**. Das ist die einzige
Seite, die überhaupt nichts voraussetzt: wozu das System da ist, wer was sehen
kann, was die Wörter am Bildschirm bedeuten, wie eine Zeitdauer geschrieben
wird und was mit einem Monat geschieht — von dem Tag, an dem er beginnt, bis zu
dem Tag, an dem er fertig ist.

Lesen Sie dann **[Meine Zeit — Ihr eigener Monat](02-my-time.md)**, die eine
Ansicht, die Sie jede Woche brauchen werden, und
**[Stunden erfassen](03-recording-hours.md)** — so kommen die Stunden dort
hinein.

Das genügt, um Ihre Arbeit zu erledigen. Der Rest steht hier für den Fall, dass
Sie ihn brauchen.

## Drei Dinge, die Sie vor allem anderen wissen sollten

**Eine Zeitdauer wird mit einem Doppelpunkt geschrieben.** `7:42` sind sieben
Stunden und zweiundvierzig Minuten. Es sind nicht sieben Komma vier zwei. Wo
eine Ansicht auch `7.7` oder `90m` annimmt, steht das auf der jeweiligen Seite.

**Ein Feiertag oder ein Urlaubstag zählt als geleistete Stunden.** Er wird zum
**Ist** dazugezählt. Er senkt nicht das **Soll**, das bei den Stunden bleibt,
die Ihre Arbeitswoche vorgibt. Ein Monat mit einem Feiertag zeigt also dasselbe
**Soll** wie ein Monat ohne, und der Feiertag erscheint stattdessen auf der
anderen Seite. Ihr **Saldo** kommt so oder so gleich heraus. Das wird am
häufigsten falsch verstanden, und [Hier beginnen](01-start-here.md) erklärt es
in Ruhe.

**Manches lässt sich nicht rückgängig machen.** Einen Monat einreichen, einen
Monat abschließen, einen Eintrag entfernen. Jede Seite sagt das, bevor sie
erklärt, wie es geht, und sagt auch, wer es zurückholen kann — falls es
überhaupt jemand kann.

## Wenn Sie nicht weiterkommen

Lesen Sie [Wenn etwas nicht funktioniert](13-when-something-goes-wrong.md) —
dort steht jede Meldung, die Ihnen am Bildschirm begegnen kann.

Wenn das nicht weiterhilft, fragen Sie die Teamleitung. Nichts hier ist so
dringend, dass man raten müsste: Eine falsche Zahl in einem Monat, der schon
abgeschlossen ist, wieder geradezubiegen macht weit mehr Arbeit als eine Frage,
die vor dem Abschluss gestellt wird.
